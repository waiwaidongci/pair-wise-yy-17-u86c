# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 复查闭环

- 巡测记录标记异常后样点转为重点保护，记录进入「异常待复查」。
- 对待复查记录点「复查登记」，填写复查人、温度、湿度、CO2和说明；弹窗内会显示关联样点基准与允许限值。
- 温度不超过基准 0.5℃、湿度不低于基准 2 个百分点、CO2 不超过基准 50ppm（均含临界值）时判为「复查达标」，记录结案为「已复查」，样点恢复常规观察。
- 任一项仍超标则判为「复查未达标」：样点保留重点保护，记录仍为「异常待复查」，本次复查结果留存并可再次登记。
- 「已复查」记录不能重复登记复查（服务端强制 409）；旧记录的复查结论与关键数值在列表和趋势看板照常展示。
