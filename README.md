# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 复查闭环

异常巡测（状态「异常待复查」）可在卡片上点「复查登记」，填写复查人、温度、湿度、CO2和说明后提交：

- 温度不超过基准 0.5℃、湿度不低于基准 2 个百分点、CO2 不超过基准 50ppm：异常结案（状态转「已复查」），样点恢复「常规观察」。
- 任一项仍超标：巡测保持「异常待复查」，样点保留「重点保护」，实测数值与结论留档，可再次登记复查。
- 已复查记录不能重复登记；列表与看板展示复查结论和关键数值。
